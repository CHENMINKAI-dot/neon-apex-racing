NEON APEX · 霓虹竞速 / v1.0

打开 index.html 即可玩，无需安装，资源均包含在文件夹中。
需要支持 WebGL 的现代浏览器；默认关闭声音，右上角可开启合成引擎音效。

W / ↑：加速    S / ↓：刹车    A D / ← →：转向
Shift：氮气    Space + 转向：漂移    C：视角    Esc / P：暂停
手机使用屏幕按键，支持同时按住油门与转向。

街头竞速：和 7 辆 AI 赛车竞速，一圈决胜。
计时挑战：单人完成一圈，刷新用时。
自由驾驶：无限循环赛道，没有终点。
最佳用时在当前浏览器本地保存，按赛道、模式与难度分别记录。

这是原创轻量街机游戏，车辆、道路和景物均用程序构建，不含真实品牌车型。
设计参考：
Asphalt Legends 官方介绍中的氮气与街机竞速节奏：
https://asphaltlegends.com/?redirection=tle_hub
